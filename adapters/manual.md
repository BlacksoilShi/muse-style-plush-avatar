# 其他模型 / 手工模式

按能力选路线，不按品牌猜功能：

- 支持图像编辑：先实际读源图提取文字线索，再分阶段只提供固定母版／上一阶段合格图作为编辑底图
- 单图编辑：同样可运行上述流程，来源照片由执行者看图而非传给模型须披露，不假装模型看到了缺失图片
- 仅文字生图：提供原创文字风格和可见特点；只能做近似角色设计，不能称照片保真转换
- 不能生成图：交付提示词，不声称生成完成

优先使用平台的自然语言提示。只有当前官方接口/界面明确存在时才使用负面提示、seed、reference weight、透明开关等参数。没有负面提示字段就把“不要……”写进主提示词。即使支持 seed，也不承诺跨模型一致。

本地执行的 Python 工具与模型无关。若模型无透明输出但可下载真正不透明RGB方图（无透明色键），按主流程评估圆形安全边界，显式加 --allow-rgb。内圆半透明也可在授权下由模型另出不透明中间图，再独立复验几何，不能用本地像素填补代替。圆内浅蓝背景会保留，脚本不抠出毛绒角色，也不会消除圈内棋盘格或白边。

如果当前产品不能执行脚本，让用户在本地运行，并明确尚未完成本地 QA；不要用口头承诺代替文件验证。上传与下载遵守用户授权及当前平台规则。
