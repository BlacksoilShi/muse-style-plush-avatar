# 其他模型 / 手工模式

按实际能力选择，不按品牌猜：

- 多参考图像编辑：A共同脸部母版在前，B外观来源在后；显式分工，实际检查输入顺序。顺序不构成权重保证
- 单图编辑：只输入A，执行者先看B并填写单图外观描述；披露B未传给模型
- 仅文字生图/形象定制：可做原创近似，不称已固定到看不到的母版
- 不能生图：交付提示词，不声称生成完成

使用 [prompts/avatar.md](../prompts/avatar.md)。首轮只一条短提示，出现具体问题才做对应修正。不要主动把同一图转发到其他服务。

仅在实际存在时才使用mask、seed、reference weight、negative prompt或透明选项；没有这些字段就用自然语言。支持seed也不等于跨模型同图。

模型决定造型，现有Python工具仅做授权的有限圆边alpha。它不能把半透明内圆补实、不能抠角色、不能修掉圈内棋盘格，也不校正脸型。未运行文件检查时应如实说明。
